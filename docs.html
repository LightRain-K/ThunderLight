📚 Программное обеспечение

Код для Arduino и Raspberry Pi, а также список необходимого ПО.

Arduino (нижний уровень)

// VRD Flight Controller — Low Level (Arduino Nano) // Стабилизация, чтение IMU, управление ESC #include <Wire.h> #include <MPU6050.h> MPU6050 imu; float pitch, roll, yaw; float targetPitch = 0, targetRoll = 0; void setup() { Serial.begin(115200); imu.initialize(); } void loop() { imu.getRotation(&pitch, &roll, &yaw); // ПИД-регулятор float errorP = targetPitch - pitch; float output = kp * errorP + ki * integral + kd * derivative; // Отправка на ESC analogWrite(ESC_PIN, output); delay(10); }

Raspberry Pi (верхний уровень)

# VRD Flight Controller — High Level (Raspberry Pi 3) # Планирование траектории, телеметрия, визуализация import serial import numpy as np import matplotlib.pyplot as plt ser = serial.Serial('/dev/ttyS0', 115200) def get_telemetry(): data = ser.readline().decode().strip().split(',') return { 'pitch': float(data[0]), 'roll': float(data[1]), 'altitude': float(data[2]) } while True: telemetry = get_telemetry() # Визуализация print(f"Pitch: {telemetry['pitch']:.2f}°")

📖 Инструкция по сборке

Пошаговое руководство по сборке аппарата.

Шаг 1: Подготовка деталей

  • Распечатайте все детали рамы на 3D-принтере
  • Проверьте наличие всех электронных компонентов
  • Подготовьте инструменты: отвёртки, пинцет, паяльник

Шаг 2: Сборка рамы

  • Соедините центральную плату с плечами рамы
  • Закрепите двигатели на концах плеч
  • Установите ESC на плечи

Шаг 3: Электроника

  • Установите Arduino Nano и Raspberry Pi на центральную плату
  • Подключите IMU MPU-6050 к Arduino
  • Подключите ESC к Arduino и аккумулятору
  • Подключите приёмник

Шаг 4: Программирование

  • Загрузите скетч в Arduino
  • Запустите Python-скрипт на Raspberry Pi
  • Настройте параметры ПИД-регулятора

🧪 Калибровка

Настройка датчиков, ESC и ПИД-регулятора.

Калибровка IMU (MPU-6050)

  • Установите аппарат на ровную поверхность
  • Запустите скетч калибровки
  • Запишите значения смещения (offset) акселерометра и гироскопа
  • Внесите значения в код

Калибровка ESC

  • Отключите пропеллеры
  • Включите питание с максимальным сигналом
  • Дождитесь звукового сигнала
  • Снизьте сигнал до минимума

Настройка ПИД-регулятора

  • Используйте симулятор ПИД для подбора коэффициентов
  • Начните с Kp = 1.2, Ki = 0.3, Kd = 0.4
  • Постепенно увеличивайте Kp до появления колебаний
  • Добавьте Kd для гашения колебаний
  • Добавьте Ki для устранения статической ошибки

🛡️ Безопасность

Правила безопасной работы с БПЛА и аккумуляторами.

Общие правила

  • Всегда проверяйте целостность конструкции перед запуском
  • Запускайте аппарат только на открытой площадке вдали от людей
  • Никогда не приближайтесь к вращающимся пропеллерам
  • При работе с БПЛА используйте защитные очки

Правила работы с Li-Po аккумуляторами

  • Заряжайте аккумуляторы только специальным зарядным устройством
  • Не оставляйте заряжающиеся аккумуляторы без присмотра
  • Храните аккумуляторы в огнеупорных контейнерах
  • Не используйте повреждённые или вздутые аккумуляторы
  • Не разряжайте аккумулятор ниже 3.0 В на элемент

Что делать в экстренной ситуации

  • При неконтролируемом полёте — немедленно отключите питание
  • При пожаре аккумулятора — используйте песок или огнетушитель (не воду!)
  • При падении — отойдите на безопасное расстояние
⚠️ ВАЖНО

Нарушение правил безопасности может привести к серьёзным травмам. Перед запуском ознакомьтесь со всеми правилами.
