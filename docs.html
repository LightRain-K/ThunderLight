📌 Введение

Данная документация представляет собой полное техническое руководство по сборке, настройке и эксплуатации образовательного конструктора БПЛА ThunderLight.

О проекте

ThunderLight — это открытая образовательная экосистема для изучения систем управления беспилотными летательными аппаратами. В основе конструктора лежит гибридная архитектура управления, состоящая из двух уровней:

  • Нижний уровень (Low_LV) — на базе Arduino Nano (ATmega328P) отвечает за чтение датчиков, стабилизацию и управление исполнительными механизмами в реальном времени.
  • Верхний уровень (Hight_LV) — на базе Raspberry Pi 3 отвечает за планирование траектории, диагностику, визуализацию и адаптацию алгоритмов.

Для кого эта документация

  • Для педагогов — методические материалы и лабораторные работы.
  • Для инженеров — технические характеристики, схемы и исходные коды.

Состав документации

  • Руководство по калибровке — настройка датчиков, ESC и ПИД-регулятора.
  • Инструкция по первому полёту — подготовка и запуск.
  • Технические данные — характеристики и результаты испытаний.
  • Правила безопасности — обязательные требования.
  • Руководство по обслуживанию — уход и ремонт.

🔧 Инструкция по сборке

Пошаговое руководство по механической сборке аппарата.

Этап 1: Подготовка деталей

Перед началом сборки убедитесь, что у вас есть все компоненты из спецификации. Подготовьте рабочее место с хорошим освещением и необходимыми инструментами:

  • Набор отвёрток (крестовая и плоская)
  • Пинцет для работы с проводами
  • Паяльник с тонким жалом (для пайки проводов)
  • Мультиметр для проверки соединений
  • Нейлоновые стяжки для кабельной обвязки

Этап 2: Сборка рамы

Рама поставляется в виде набора 3D-печатных деталей. Следуйте инструкции:

  1. Центральная плата: Установите центральную плату на ровную поверхность. Это основа всей конструкции.
  2. Плечи рамы: Прикрепите четыре плеча к центральной плате с помощью винтов M3. Убедитесь, что плечи расположены симметрично под углом 90° друг к другу.
  3. Крепление двигателей: Установите двигатели на концах плечей. Закрепите их винтами, входящими в комплект двигателей.
  4. Крепление ESC: Закрепите регуляторы скорости на плечах с помощью нейлоновых стяжек. Расположите их близко к двигателям для минимизации силовых проводов.

Этап 3: Монтаж электроники

  1. Arduino Nano: Установите Arduino Nano на центральную плату с помощью нейлоновых стоек.
  2. Raspberry Pi: Закрепите Raspberry Pi на центральной плате рядом с Arduino. Используйте стойки для обеспечения вентиляции.
  3. IMU MPU-6050: Установите датчик в центре платы, строго параллельно плоскости. Это критично для точности стабилизации.
  4. Приёмник (опционально): Установите приёмник в удобном месте, обеспечив доступ к антеннам.

Этап 4: Электрические соединения

  1. Питание: Подключите аккумулятор к распределителю питания. Проверьте полярность!
  2. ESC: Подключите сигнальные провода ESC к выходам Arduino (D3, D5, D6, D9). Подключите силовые провода ESC к распределителю питания.
  3. IMU: Подключите MPU-6050 к Arduino по шине I2C (SDA → A4, SCL → A5).
  4. UART: Соедините Arduino и Raspberry Pi по последовательному порту (Arduino D0 → RPi GPIO15, Arduino D1 → RPi GPIO14).

Этап 5: Установка пропеллеров

  1. Установите пропеллеры на валы двигателей.
  2. Важно: Убедитесь, что направление вращения соответствует схеме (два пропеллера по часовой стрелке, два — против).
  3. Закрепите пропеллеры гайками, входящими в комплект двигателей.
⚠️ Критическое предупреждение
  • Перед установкой пропеллеров обязательно откалибруйте ESC (см. раздел "Калибровка").
  • Никогда не включайте питание без установленных пропеллеров — это может повредить двигатели.

💾 Прошивка и программное обеспечение

Инструкция по загрузке прошивки в Arduino и настройке Raspberry Pi.

Установка ПО на компьютер

  1. Arduino IDE: Скачайте и установите Arduino IDE с официального сайта (версия 1.8.19 или новее).
  2. Библиотеки Arduino: Установите необходимые библиотеки через менеджер библиотек:
    • Wire — для работы с I2C (установлена по умолчанию)
    • MPU6050 — для работы с датчиком
    • Servo — для управления сервоприводами
  3. Python: Установите Python 3.9 или новее на Raspberry Pi.
  4. Библиотеки Python: Установите необходимые пакеты:
    pip install pyserial numpy matplotlib

Загрузка прошивки в Arduino

  1. Подключите Arduino Nano к компьютеру через USB-кабель.
  2. Откройте Arduino IDE и загрузите скетч VRD_Flight_Controller.ino (доступен в репозитории).
  3. Выберите плату: Arduino Nano (процессор ATmega328P).
  4. Выберите порт, к которому подключена плата.
  5. Нажмите Загрузить.
// VRD Flight Controller — Low Level (Arduino Nano) // Версия 1.0 — базовая стабилизация #include <Wire.h> #include <MPU6050.h> #include <Servo.h> MPU6050 imu; Servo esc1, esc2, esc3, esc4; // ПИД-коэффициенты float kp = 1.2, ki = 0.3, kd = 0.4; float integral = 0, lastError = 0; void setup() { Serial.begin(115200); Wire.begin(); imu.initialize(); esc1.attach(3); esc2.attach(5); esc3.attach(6); esc4.attach(9); // Калибровка ESC calibrateESC(); } void loop() { // Чтение данных с IMU imu.getMotion6(&ax, &ay, &az, &gx, &gy, &gz); // Фильтр и расчёт углов calculateAngles(ax, ay, az, gx, gy, gz); // ПИД-регулятор float output = pidCalculate(targetAngle, currentAngle); // Отправка на ESC esc1.writeMicroseconds(output); esc2.writeMicroseconds(output); esc3.writeMicroseconds(output); esc4.writeMicroseconds(output); // Отправка телеметрии на Raspberry Pi sendTelemetry(); delay(10); }

Настройка Raspberry Pi

  1. Подключитесь к Raspberry Pi через SSH или используйте монитор и клавиатуру.
  2. Склонируйте репозиторий проекта:
    git clone https://github.com/LightRain-K/ThunderLight.git
  3. Перейдите в директорию с Python-скриптом и запустите его:
    cd ThunderLight/firmware/python python3 telemetry.py

🧪 Калибровка

Настройка датчиков и регуляторов скорости.

Калибровка IMU (MPU-6050)

Датчик MPU-6050 требует калибровки для компенсации смещений (offset) акселерометра и гироскопа.

  1. Установите аппарат на абсолютно ровную горизонтальную поверхность.
  2. Загрузите в Arduino калибровочный скетч (доступен в репозитории).
  3. Откройте монитор порта (Serial Monitor) на скорости 115200 бод.
  4. Запишите значения смещения, которые выводятся в монитор порта.
  5. Внесите полученные значения в основной скетч в функцию imu.setAccelOffset() и imu.setGyroOffset().

Калибровка ESC

Регуляторы скорости (ESC) необходимо откалибровать для согласования диапазона сигнала.

⚠️ Важно

Перед калибровкой ESC обязательно снимите пропеллеры!

  1. Отключите аккумулятор от аппарата.
  2. Загрузите в Arduino калибровочный скетч ESC.
  3. Установите максимальный сигнал (2000 мкс).
  4. Подключите аккумулятор. ESC издадут звуковой сигнал.
  5. Установите минимальный сигнал (1000 мкс). ESC издадут второй звуковой сигнал.
  6. Калибровка завершена. Отключите питание.

Проверка работы ESC

После калибровки проверьте работу каждого ESC по отдельности:

  1. Подключите аккумулятор.
  2. Отправляйте команды через монитор порта (например, "1000", "1500", "2000").
  3. Наблюдайте за вращением двигателей. Все двигатели должны вращаться синхронно.

🎯 Настройка ПИД-регулятора

Руководство по настройке коэффициентов ПИД-регулятора для стабильного полёта.

Что такое ПИД-регулятор

ПИД-регулятор (пропорционально-интегрально-дифференциальный) — это алгоритм управления, который вычисляет управляющий сигнал на основе трёх составляющих:

  • Пропорциональная (P) — реагирует на текущую ошибку. Увеличивает скорость реакции.
  • Интегральная (I) — накапливает ошибку во времени. Устраняет статическую ошибку.
  • Дифференциальная (D) — реагирует на скорость изменения ошибки. Гасит колебания.

Рекомендуемый порядок настройки

  1. Начните с Kp: Установите Ki = 0, Kd = 0. Увеличивайте Kp до появления колебаний, затем уменьшите на 20-30%.
  2. Добавьте Kd: Увеличивайте Kd, пока колебания не будут полностью погашены.
  3. Добавьте Ki: Увеличивайте Ki для устранения статической ошибки (отклонения от целевого угла).
  4. Проверьте в динамике: Подайте возмущение (отклоните аппарат рукой) и наблюдайте за возвратом в исходное положение.

Стартовые значения

Kp (Пропорциональный)1.2
Ki (Интегральный)0.3
Kd (Дифференциальный)0.4
Частота ПИД100 Гц

Использование симулятора

Для предварительной настройки рекомендуется использовать интерактивный симулятор ПИД-регулятора. Это позволяет безопасно подобрать коэффициенты перед запуском реального аппарата.

Признаки неправильных коэффициентов

  • Слишком высокий Kp: Резкие колебания, аппарат "дрожит".
  • Слишком низкий Kp: Медленная реакция, аппарат "вялый".
  • Слишком высокий Kd: Замедленная реакция, "зажатость".
  • Слишком высокий Ki: Интегральное насыщение, аппарат "плывёт".

✈️ Первый полёт

Подготовка и проведение первого испытательного полёта.

Предполётная проверка

  1. Визуальный осмотр: Проверьте все винтовые соединения, целостность рамы и пропеллеров.
  2. Балансировка: Убедитесь, что центр тяжести находится в центре аппарата.
  3. Направление вращения: Проверьте, что все двигатели вращаются в правильном направлении.
  4. ПИД-коэффициенты: Убедитесь, что параметры ПИД загружены в контроллер.
  5. Аккумулятор: Проверьте уровень заряда аккумулятора (должен быть ≥ 11.4 В для 3S).

Выбор места

  • Выберите открытую площадку размером не менее 20×20 метров.
  • Убедитесь в отсутствии людей и животных в зоне полёта.
  • Проверьте отсутствие линий электропередач и высоких деревьев.

Процедура запуска

  1. Установите аппарат на ровную горизонтальную поверхность.
  2. Включите питание (подключите аккумулятор).
  3. Дождитесь инициализации датчиков (светодиод на Arduino перестанет мигать).
  4. Медленно увеличивайте газ до отрыва от земли.
  5. Зафиксируйте аппарат на высоте 0.5-1 метра.
  6. Наблюдайте за поведением — аппарат должен висеть стабильно, без колебаний.
  7. При отклонениях — посадите аппарат и скорректируйте ПИД-коэффициенты.
⚠️ Критическое предупреждение
  • При первых признаках нестабильности — немедленно снижайте газ и сажайте аппарат.
  • Никогда не летайте над людьми или транспортными средствами.

🛡️ Правила безопасности

Обязательные правила безопасной работы с БПЛА и аккумуляторами.

Общие правила безопасности

  • Всегда проверяйте целостность конструкции перед каждым запуском.
  • Запускайте аппарат только на открытой площадке, вдали от людей, животных и зданий.
  • Никогда не приближайтесь к вращающимся пропеллерам.
  • Используйте защитные очки при работе с аппаратом.
  • Не летайте в дождь, снег или сильный ветер.

Правила работы с Li-Po аккумуляторами

⚠️ Li-Po аккумуляторы пожароопасны

Нарушение правил работы с Li-Po аккумуляторами может привести к возгоранию.

  • Заряжайте аккумуляторы только специальным Li-Po зарядным устройством с балансиром.
  • Не оставляйте заряжающиеся аккумуляторы без присмотра.
  • Храните аккумуляторы в огнеупорных контейнерах при температуре 15-25°C.
  • Не используйте повреждённые, вздутые или деформированные аккумуляторы.
  • Не разряжайте аккумулятор ниже 3.0 В на элемент.
  • Транспортируйте аккумуляторы в специальных сумках.

Действия в экстренной ситуации

  • При неконтролируемом полёте — немедленно отключите питание (выдерните аккумулятор).
  • При пожаре аккумулятора — используйте песок, сухой огнетушитель или накройте плотной тканью. Никогда не используйте воду!
  • При падении аппарата — отойдите на безопасное расстояние, подождите, пока пропеллеры остановятся.
  • При травме — немедленно обратитесь за медицинской помощью.

🔧 Обслуживание и ремонт

Рекомендации по уходу, обслуживанию и ремонту аппарата.

Регулярное обслуживание

  • После каждых 10 полётов: Проверяйте затяжку винтов, состояние пропеллеров и проводов.
  • Ежемесячно: Проверяйте калибровку датчиков IMU.
  • При обнаружении вибраций: Проверьте балансировку пропеллеров и состояние подшипников двигателей.

Замена пропеллеров

Пропеллеры являются расходным материалом и подлежат замене при появлении трещин, сколов или дисбаланса.

  1. Снимите гайку крепления пропеллера.
  2. Снимите повреждённый пропеллер.
  3. Установите новый пропеллер, соблюдая направление вращения.
  4. Закрепите гайкой. Не перетягивайте!

Замена двигателя

  1. Отключите аккумулятор.
  2. Отпаяйте или отсоедините провода ESC.
  3. Открутите винты крепления двигателя.
  4. Установите новый двигатель.
  5. Подключите провода ESC (соблюдайте цветовую маркировку).
  6. Проверьте направление вращения.
📦 Запасные части

Рекомендуется иметь в запасе:

  • Комплект пропеллеров (4 шт.)
  • Комплект нейлоновых стяжек
  • Запасной двигатель (1 шт.)
  • Запасной ESC (1 шт.)

Хранение аппарата

  • Храните аппарат в сухом, прохладном месте.
  • Не храните с установленным аккумулятором.
  • Защищайте от прямых солнечных лучей.
