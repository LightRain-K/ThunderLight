Частые вопросы

Файлы загружаются на сервер? Нет. PDF обрабатывается в браузере библиотеками pdf-lib и pdf.js, файл не уходит в сеть.

Почему «Оптимизация» почти не уменьшает размер? Основной вес PDF — встроенные изображения. Без их перекодирования сильно сжать нельзя. Для сканов используйте режим «в изображения».

Безопасно ли для документов с персональными данными? Да, в отличие от онлайн-конвертеров, файл не отправляется третьим лицам.
