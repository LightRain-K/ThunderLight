    Как установить

    1. Нажмите «Скачать APK» и дождитесь загрузки файла.
    2. Откройте скачанный файл thunderlight.apk.
    3. Разрешите установку из этого источника, если Android попросит.
    4. Нажмите «Установить» — готово, откройте ThunderLight.
    Если браузер предупреждает о файле — это нормально для APK вне Google Play. APK подписан ключом ThunderLight, обновления устанавливаются поверх без потери данных.
