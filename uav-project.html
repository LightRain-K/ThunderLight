🧩 Компоненты

Шесть частей экосистемы

Каждый компонент решает свою задачу и связан с другими в единую систему.

📚

Документация

Полное руководство по сборке, настройке и эксплуатации БПЛА. Схемы, 3D-модели, код.
🧪

Lab

Интерактивные эксперименты с параметрами полёта. Найди устойчивую конфигурацию самолёта.
💻

Simulator

Инженерный симулятор полёта. Настраивай ПИД-регулятор и проверяй алгоритмы управления.
🛠️

Builder

Виртуальный конструктор БПЛА. Собирай конфигурацию и получай расчёт параметров.
🧠

VRD FC

Полётный контроллер с гибридной архитектурой: Arduino (C++) для реального времени и Raspberry Pi (Python) для планирования.
🛩️

Real UAV

Физический прототип. Проверяй алгоритмы на реальном объекте и анализируй телеметрию.
⚙️ Технические характеристики

VRD Flight Controller

Гибридная двухуровневая архитектура, объединяющая надёжность и гибкость.

📟 Нижний уровень (Low_LV)

  • • Платформа: Arduino Nano (ATmega328P)
  • • Язык: C++
  • • Датчик: IMU MPU-6050
  • • Задачи: стабилизация, управление сервоприводами
  • • Режим: жёсткое реальное время

🧠 Верхний уровень (Hight_LV)

  • • Платформа: Raspberry Pi 3
  • • Язык: Python
  • • Задачи: планирование траектории, диагностика
  • • Визуализация: телеметрия в реальном времени
  • • Потенциал: нейросети для распознавания ситуаций

📊 Результаты испытаний

  • • Ошибка стабилизации: ≤ 1.2° (требование 2°)
  • • Время отклика: 0.35 с (требование 0.5 с)
  • • Время восстановления: 0.7 с (требование 1.0 с)
  • • Отклонение от траектории: 0.82% (требование 1%)
  • ✅ Все требования выполнены с запасом
