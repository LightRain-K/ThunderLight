🐍 Python

Введение в Python

Знакомство с языком программирования Python. Установка, среда разработки и первая программа.

Цель урока: Понять, что такое Python, установить среду разработки и написать первую программу.

Что такое Python?

Python — это высокоуровневый язык программирования, который широко используется в науке, инженерии, анализе данных и автоматизации. Он известен своей простотой и читаемостью кода.

💡 Факт:

Python назван в честь комедийного шоу "Монти Пайтон", а не в честь змеи!

Установка Python

  1. Перейдите на официальный сайт python.org
  2. Скачайте последнюю версию для вашей операционной системы
  3. Запустите установщик и следуйте инструкциям
  4. Важно: Отметьте галочку "Add Python to PATH"

Первая программа — "Hello, World!"

Создайте файл с расширением .py и напишите:

# Первая программа на Python print("Hello, World!")

Запустите программу командой python hello.py в терминале или нажмите кнопку "Run" в вашей среде разработки.

Интерактивный режим

Python можно использовать в интерактивном режиме, вводя команды прямо в терминале. Это отличный способ для экспериментов.

# Введите в терминале "python" >>> print("Hello") Hello >>> 2 + 2 4
