Переменные и типы данных

Изучаем основы хранения данных: числа, строки, списки и словари. Учимся работать с переменными.

Цель урока: Научиться создавать переменные, понимать основные типы данных и работать с ними.

Что такое переменная?

Переменная — это контейнер для хранения данных. Представь себе коробку с названием, в которую можно положить что угодно: число, текст, список.

# Создание переменных name = "Алексей" # строка (текст) age = 25 # целое число height = 1.75 # число с плавающей точкой is_student = True # булево значение (True/False)
💡 Правила именования:
  • Имя переменной должно начинаться с буквы или подчёркивания
  • Может содержать буквы, цифры и подчёркивания
  • Регистр имеет значение: age и Age — разные переменные

Основные типы данных

В Python есть несколько встроенных типов данных. Самые распространённые:

1. Числа (int, float)

  • int — целые числа: 10, -5, 0
  • float — числа с плавающей точкой: 3.14, -0.5, 2.0
# Работа с числами x = 10 y = 3.5 sum = x + y print(sum) # 13.5

2. Строки (str)

Строка — это последовательность символов. Записывается в кавычках (одинарных или двойных).

# Работа со строками name = "Алексей" greeting = "Привет, " + name print(greeting) # "Привет, Алексей"

3. Списки (list)

Список — это упорядоченная коллекция элементов. Элементы могут быть разных типов.

# Создание списка fruits = ["яблоко", "банан", "апельсин"] print(fruits[0]) # "яблоко" (индексация с 0) fruits.append("киви") # добавление элемента print(fruits) # ["яблоко", "банан", "апельсин", "киви"]

4. Словари (dict)

Словарь — это коллекция пар ключ: значение. Позволяет хранить структурированные данные.

# Создание словаря person = { "name": "Алексей", "age": 25, "city": "Москва" } print(person["name"]) # "Алексей" person["job"] = "инженер" # добавление нового ключа

5. Булевы значения (bool)

Булевы значения — это True (истина) и False (ложь). Используются в условиях и сравнениях.

is_student = True is_teacher = False print(is_student and is_teacher) # False

Определение типа данных

Функция type() показывает тип данных переменной:

print(type(10)) # print(type(3.14)) # print(type("Hello")) # print(type([1, 2, 3])) # print(type({"a": 1})) #

Преобразование типов

Иногда нужно преобразовать данные из одного типа в другой:

# Преобразование типов x = 10 y = "5" result = x + int(y) # преобразуем строку в число print(result) # 15 text = "Число: " + str(x) # преобразуем число в строку print(text) # "Число: 10"
📌 Практическое задание

Создай переменные для хранения твоих данных:

  • Имя (строка)
  • Возраст (целое число)
  • Рост (число с плавающей точкой)
  • Любимые цвета (список из 3 строк)
  • Информация о себе (словарь с ключами: name, age, city)

Выведи все данные на экран с помощью print().
