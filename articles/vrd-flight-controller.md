# 🚀 VRD Flight Controller

**VRD_flight_controller** — это проект по созданию высоконадёжного полётного контроллера для ракеты-носителя с воздушно-реактивным двигателем (ВРД) и горизонтальным взлётом. Система также адаптируется для задач воздушного старта.

Проект находится в **активной стадии разработки**, и его главная цель — обеспечить максимальную отказоустойчивость и адаптивность в нестандартных ситуациях.

## 🎯 Ключевые особенности

1.  **Гибридная двухъядерная архитектура**  
    Вычисления разделены на два уровня:
    *   **Высокоуровневый (Hight_LV):** Отвечает за стратегические решения, обработку данных с датчиков и взаимодействие с ИИ. Может работать в алгоритмическом или AI-режиме.
    *   **Низкоуровневый (Low_LV):** Обеспечивает непосредственное управление исполнительными механизмами (рули, дроссель, газ), сбор телеметрии и работает в реальном времени.
    
    Такое разделение повышает **отказоустойчивость**: даже при сбое высокоуровневой логики низкоуровневый контроллер может удержать аппарат в безопасном режиме.

2.  **Машинное обучение для аварийных ситуаций**  
    После запуска макета и тестирования алгоритмов планируется сбор телеметрии для обучения нейросетевой модели. Она будет помогать контроллеру **реагировать на нештатные ситуации** быстрее и точнее, чем это возможно с помощью заранее запрограммированных правил.

3.  **Симуляционная среда**  
    В репозитории есть папка `Simulation/`, содержащая инструменты для тестирования логики контроллера в виртуальной среде до реальных полётов. Это позволяет отлаживать алгоритмы без риска для оборудования.

## 🗂️ Структура репозитория

Проект организован в несколько ключевых директорий:

*   **`Hight_LV(optional) AI/`** — экспериментальный контроллер на основе нейросетей (в разработке).
*   **`Hight_LV(optional)algoritmic/`** — алгоритмическая версия высокоуровневой логики (основная на данный момент).
*   **`Simulation/`** — скрипты и модели для симуляции полёта.
*   **`samolet/`** и **`samolet2/`** — ранние версии и тестовые стенды для отработки управления.
*   **`LICENSE`** — лицензия MIT, что означает открытость кода для использования и модификации.

## 🔧 Технологический стек

*   **Языки:** Вероятно, C/C++ для низкоуровневого ПО и Python для высокоуровневых алгоритмов и симуляций (исходя из структуры).
*   **Вычислительная платформа:** Рассматриваются два варианта:
    *   Микроконтроллеры (STM32, ESP32) для низкого уровня.
    *   Одноплатные компьютеры (Raspberry Pi, Orange Pi) для высокоуровневых задач и ИИ.

## 🧪 Статус и планы

*   **Текущий этап:** Разработка и отладка алгоритмов управления в симуляции. Сбор данных с тестовых стендов.
*   **Ближайшие планы:**
    *   Интеграция низко- и высокоуровневой логики на реальном железе.
    *   Проведение первых испытаний на наземном стенде.
    *   Начало сбора данных для обучения ИИ.
*   **Перспектива:** Создание полностью автономной, самообучающейся системы управления для суборбитальных полётов.
